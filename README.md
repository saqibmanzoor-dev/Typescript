# TypeScript Learning Examples

This project is a small collection of TypeScript practice files. It shows how TypeScript adds type information to JavaScript, helping developers catch mistakes before running code.

## What this project teaches

- Basic types such as `number`, `string`, and `boolean`
- Function parameter and return types
- Type inference, where TypeScript works out a value's type
- Custom object shapes with `type` and `interface`
- Optional properties with `?`
- Union types with `|` and intersection types with `&`
- Arrays, filtering, and finding a maximum value
- Classes that implement an interface

## Project structure

- `class_1/index.ts` introduces typed variables and functions.
- `class2/type.ts` practises object types, unions, and intersections.
- `class2/interferance.ts` covers typed functions, interfaces, and classes.
- `class2/assignment.ts` contains union-type and array exercises.

## Run an example

Install dependencies in the folder that contains the example, then compile a file with TypeScript:

```powershell
npm install
npx tsc index.ts
```

The examples are intended for learning, so each file focuses on a small TypeScript concept.
